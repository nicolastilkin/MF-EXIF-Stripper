Method

This is a container rewrite, not a re-encode. The JPEG entropy-coded scan and the PNG IDAT stream are copied across untouched, so the output decodes to pixels identical to the input. Canvas-based strippers — the usual browser approach — decode and re-compress, which loses quality on every pass, drops alpha on JPEG conversion and silently changes the file size.

APP14 Adobe is always retained. It declares the YCCK/CMYK colour transform, and tools that blanket-delete every APPn segment turn Adobe-authored CMYK JPEGs inverted. acTL/fcTL/fdAT are likewise retained, or an APNG collapses to a still frame.

Nothing here touches the network. There is no fetch, no XHR, no external stylesheet or script, and no storage API — state lives in the tab and dies with it.
